# قائمة فحص بحث GitHub

استخدم هذا المرجع عند الانتقال من فكرة عامة إلى بحث قابل للتحقق.

## أوامر قراءة آمنة

```bash
gh search repos "<problem keywords>" --limit 10 --json fullName,description,url,updatedAt,license

gh repo view OWNER/REPO --json nameWithOwner,description,url,defaultBranchRef,license,pushedAt

gh api repos/OWNER/REPO/contents/README.md
```

لا تعتمد على نتائج البحث وحدها. افتح صفحة المصدر أو اقرأ الملفات الفعلية، وتحقق من أن المستودع هو المقصود وأن النشاط ليس مجرد نسخة أو مرآة.

## فحص الترخيص

ابحث عن `LICENSE`, `COPYING`, وحقول الترخيص في `package.json`, `pyproject.toml`, أو ملفات الإعداد. سجّل:

- نوع الترخيص وإصداره.
- هل يسمح بالاستخدام التجاري والتعديل والتوزيع؟
- هل توجد شروط نسب أو مشاركة التعديلات؟
- هل توجد ملفات أو نماذج أو بيانات بترخيص مختلف؟
- هل الترخيص غائب أو مخصص؟ عندها اعتبر إعادة الاستخدام غير واضحة واطلب مراجعة قانونية قبل التوزيع.

## بطاقة المصدر

```text
المصدر:
الرابط:
الغرض الأصلي:
المكوّن أو النمط الملهم:
الملفات المقروءة:
آخر تحديث/الإصدار:
الترخيص:
التبعيات الحساسة:
مخاطر الأمن أو الخصوصية:
ما الذي لن ننسخه:
درجة الثقة:
```

## قاعدة الدمج

لا تقترح دمج مصدر في منتج قبل الإجابة عن ثلاثة أسئلة:

1. هل نفهم الترخيص والتبعيات؟
2. هل يمكن اختبار المكوّن مستقلًا؟
3. هل يضيف قيمة لا يمكن الحصول عليها بمكوّن أبسط؟

إذا كانت الإجابة «لا» على أي منها، اقترح تجربة معزولة أو استخدم المصدر للإلهام فقط.
